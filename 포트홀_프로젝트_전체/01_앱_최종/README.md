## 최종 제출 전에
테스트 포트홀을 끄려면 `소스코드/www/app.js` 에서 `const USE_TEST_POTHOLES = true;` 를 `false` 로 바꾸고 다시 빌드한다 (코드_설명.md의 빌드 방법).

## 테스트할 것
- 블랙박스 연결: 실기기에서 와이파이+LTE 동시 사용 미확인
- 주변 알림: 화면 꺼짐·잠금화면·음성 실기기 미확인

- 운행 중 위치 올리기(1.0.4-test): 실기기에서 화면 꺼진 상태로 gps_logs 에 2초마다 쌓이는지 미확인
