# 포트홀 감지 프로젝트 (캡스톤 · 깁미깁미)

차량 충격으로 포트홀을 감지해서 위치와 사진을 서버에 올리고, 다른 운전자에게 알려주는 프로젝트.

- **블랙박스** (케이스 안): 라즈베리파이 5 + 가속도 센서 + 갤럭시 S23(카메라 역할만)
- **운전자 스마트폰**: 포트홀 알리미 앱 → GPS 위치 붙이기 + 서버 업로드 + 지도·알림
- **서버**: Supabase

## 테스트 앱 자동 빌드

`www/` 나 `android/` 를 고쳐서 main 에 올리면 GitHub Actions 가 알아서:

- **APK**: Actions 탭 → 최신 build → Artifacts 의 `pothole-test-apk`
- **웹페이지**: GitHub Pages (Settings → Pages 에 주소 있음)

테스트 앱 감지 방식은 C SDK와 같아: |크기 − 1g|, 0.05초 평균, 쿨다운 2초. 화면이 켜져 있을 때만 동작해.

## 주의

- Supabase **secret / service_role 키는 절대 올리지 않기.** 공개(publishable) 키만 사용.
- 테스트용 RLS 정책(`포트홀_프로젝트_전체/11_서버_Supabase/테스트용_SQL.sql`)은 시연 끝나면 지우기.
