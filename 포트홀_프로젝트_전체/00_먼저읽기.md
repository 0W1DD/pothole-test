## 1. 한 줄 요약

**블랙박스에 이미 있는 가속도 센서로 포트홀 충격을 감지하고(초경량 C SDK), 그 순간 사진과 위치를 서버로 보내 AI가 한 번 더 확인한 뒤, 지도에 표시하고 배상청구까지 돕는 서비스.**

## 2. 전체 흐름

```
[블랙박스 = 라즈베리파이 5 시제품]
  가속도 센서(ADXL345, 1초 400번)
    → 충격 감지 SDK (C 코드 644바이트)
        충격점수 = | √(x²+y²+z²) − 1g |, 0.05초 평균
        기준값(0.20g) 넘으면 "충격!" (2초간 중복 금지)
        속도로 "몇 초 전 화면에 포트홀이 찍혔는지" 계산
    → 그 순간 사진 (블랙박스 카메라 = 케이스에 끼운 갤럭시 S23, 파이와 USB 연결)
          │
          ├─ 커넥티드형(A형): 블랙박스가 LTE로 서버에 바로 전송
          └─ 스마트폰 연동형(B형): 블랙박스 와이파이 → 운전자 폰의 앱이 받아서 GPS 위치 붙여 LTE로 전송
                (와이파이는 블랙박스 전용 통로, 인터넷은 LTE 그대로)

※ 역할 구분
  - 갤럭시 S23 울트라 = 블랙박스의 **카메라 역할만** (GPS·업로드 안 함)
  - 운전자 스마트폰 = 포트홀 알리미 앱: **GPS 위치 붙이기 + 서버 업로드 + 지도·알림**
          ▼
[서버 = Supabase]
  potholes(포트홀), gps_logs(차 위치), shock_events(충격 신호), pothole-images(사진)
    → AI(YOLO26n)로 사진 재확인 → 진짜 포트홀만 남김   ← 아직 연결 전 (앞으로 할 일)
          ▼
[앱 "포트홀 알리미"]
  지도 핀(빨강 발견 / 파랑 수리중) · 주변 포트홀 음성 안내
  배상청구 후기 커뮤니티 · 배상청구 도우미(필요서류 체크리스트) · 블랙박스 연결
```

### 블랙박스 3분류 (발표용)

| 분류 | 대상 | 사용자 부담 |
|---|---|---|
| 커넥티드형 (A형) | LTE 블랙박스 | 없음 |
| 스마트폰 연동형 (B형) | 와이파이 블랙박스 (시중에서 가장 흔함) | 처음 한 번 연결 허용 |
| 지원 대상 외 | 통신 기능 없는 블랙박스 | 스마트폰 앱 단독 모드로 참여 |

다나와 인기 상위 10개 블랙박스 중 9개가 지원 대상 (2026.11 직접 조사)

## 5. 솔직한 현재 상태

**된 것**
- SDK 완성, 실차 캘리브레이션, 공개 데이터 검증
- 최종 앱 (최신 1.0.3-test): 지도, 커뮤니티, 배상청구 도우미, 카카오 로그인, 블랙박스 와이파이 연결(받기까지), 주변 포트홀 음성 안내
- 테스트 앱: 사진 업로드, A형(shock_events), B형(파이 와이파이 → 대기열 → 업로드). 실험용이라 폰 한 대가 카메라와 GPS를 둘 다 맡았음
- 케이스 설계 v3c (실측 반영, 나사·케이블타이 없이 조립)
- 판넬, 장착 시뮬레이션 영상, 실차 데이터 영상

**아직 안 된 것 (기말 전 할 일)**
1. **실물 통합 시연**: 파이 센서 → 사진 → 서버 → 지도 핀을 한 번에 이어서 보여주기
2. **최종 앱의 B형 자동 업로드**: 최종 앱은 블랙박스에서 기록·사진을 **받기까지만** 함. 서버에 자동으로 올리는 건 테스트 앱에만 있음 → 테스트 앱 코드를 최종 앱으로 옮겨야 함
3. **와이파이·LTE 동시 사용 실기기 확인**: 코드와 빌드는 됐지만 실제 폰에서 "업로드 다 됨"을 아직 못 봄
4. **AI(YOLO) 서버 연결**: 올라온 사진을 자동으로 확인하는 서버(라즈베리파이 4 예정)
5. **오감지 14번 중 몇 개를 AI가 거르는지** 숫자로 측정
6. **케이스 출력** (선배와 Craft-LAB 211호, 이번 주)
7. **S23 카메라를 파이에서 찍는 코드**: S23을 파이에 USB로 연결해 블랙박스 카메라로 쓰기 (안드로이드 'USB 웹캠' 모드 확인 필요). 지금 파이 코드는 IP캠 주소나 예시 사진만 씀
8. 테스트용으로 열어둔 Supabase 보안 정책(RLS) 닫기

자세한 측정 순서는 **앞으로_측정_방법.md** 참고.

## 6. 장비

| 장비 | 역할 |
|---|---|
| 라즈베리파이 5 | 블랙박스 시제품 (USB 메모리 부팅) |
| 라즈베리파이 4 × 2 | 예정: YOLO 확인 서버 / 두 번째 블랙박스 또는 상황판 |
| ADXL345 (keyes 보드, 약 28×21mm) | 가속도 센서, I2C 0x53, ±16g, 400Hz |
| 18650 × 2 UPS 보드 | 독립 전원 (황동 기둥 6mm로 파이와 띄움, 전원은 선으로) |
| 갤럭시 S23 울트라 | **블랙박스 카메라 역할만** (케이스에 끼우고 파이와 USB 연결) |
| 운전자 스마트폰 | 포트홀 알리미 앱: GPS 위치 + 업로드 + 지도·주변 알림 |
| USB GPS (/dev/ttyACM0) | 파이 위치 (선택) |

**파이 5 전원 주의**: 보조배터리·UPS로 켜면 무한 재부팅됨 → EEPROM `PSU_MAX_CURRENT=5000`, config.txt `usb_max_current_enable=1` 로 해결함 (이미 설정됨)

## 7. 보안 메모

- 앱과 코드에 들어 있는 Supabase 키는 **공개용(publishable) 키**라서 앱에 들어가도 되는 키다.
- **secret / service_role 키는 절대 코드·앱·이 zip에 넣지 않는다.**
- 테스트하면서 "누구나 올릴 수 있게" 열어둔 정책은 발표 끝나면 닫는다 (`11_서버_Supabase` 참고).
- 카드 사진, 개인 연락처가 나온 캡처는 이 zip에 넣지 않았다.
