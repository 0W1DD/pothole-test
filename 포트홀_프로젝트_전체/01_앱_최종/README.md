## 최종 제출 전에
테스트 포트홀을 끄려면 `소스코드/www/app.js` 에서 `const USE_TEST_POTHOLES = true;` 를 `false` 로 바꾸고 다시 빌드한다 (코드_설명.md의 빌드 방법).
