# 블랙박스 시연용 케이스 (최종 v3c)

갤럭시 S23 울트라(**블랙박스 카메라 역할**) 뒷면에 끼우는 케이스. 안에 18650 UPS + 라즈베리파이 5(황동 기둥 6mm) + ADXL345 센서.

| 파일 | 용도 |
|---|---|
| `blackbox_v3c_body.step`, `blackbox_v3c_lid.step` | **출력용 (선배에게 보낼 파일)**. CATIA 등에서 열림 (설계 기록 없는 솔리드) |
| `blackbox_v3c_body.stl`, `blackbox_v3c_lid.stl` | 슬라이서에 바로 넣는 파일 |
| `케이스_v3c_미리보기.png` | 모양 |
| `make_case_v3c.py` | 치수 숫자만 바꾸면 다시 생성 (`pip install manifold3d trimesh numpy` 후 `python3 make_case_v3c.py`) |
| `stl2step.py` | STL → STEP 변환 (`pip install cadquery-ocp`) |
| `이전버전/` | v2(핀·전선), v3(바깥 고리), v3b(고리 없음) |

## 치수 (2026-11-17 줄자 실측 반영)
- 바깥: 88 × 103 × 72mm (폰 포함 두께)
- 폰(케이스 포함) 81.5 × 166 × 11.5 기준, 여유 1mm
- 폰 뒷면 기준: 배터리판 윗면 25.1, 파이 기판 윗면 32.7(실측 32.5), 포트 꼭대기 48.7, 뚜껑 아랫면 56
- 센서 보드 28 × 21mm, 긴 변을 세워서 바닥 홈에 끼움

## 조립 (나사·케이블타이 없음)
1. 폰을 카메라 쪽에서 밀어 넣기 (카메라 섬은 그대로 노출, 버튼 쪽 벽은 비어 있음)
2. 배터리+파이 스택을 위에서 넣기 (양옆 낮은 칸막이 사이)
3. 센서를 GPIO 쪽 옆 칸 바닥 홈에 세워 끼우기 (점퍼선 4핀이 카메라 쪽을 향하게)
4. 전원선: 배터리판 출력 → 안쪽 USB-C 쪽 빈 칸(폭 약 14mm)에 접어 넣기 → 옆벽 창으로 파이 USB-C
5. 카메라 선: 끝 벽 위쪽 구멍(파이 USB) → 아래로 폰 충전단자
6. 뚜껑을 위에서 끼움. 안쪽 기둥이 파이 모서리와 센서 윗변을 눌러 고정 (헐거우면 기둥 끝에 양면테이프)

## 출력
- 본체: 화면 쪽 턱을 바닥으로, **서포트 켜기**
- 뚜껑: 이미 뒤집혀 있음 (윗면이 바닥), 서포트 없이 가능
- 재료 대략 100g 내외 (슬라이서에서 확인)
- Craft-LAB(천안공과대학 기초융합실습관 211호), 선배에게 STEP 파일 전달 후 같이 출력

## 확인 필요
- UPS 전원 버튼·LED 창 위치는 사진으로 확실치 않음 → 실물 보고 조정
- USB 메모리는 끝 벽 밖으로 약 4cm 튀어나옴 (크기 유지를 위해)
- 실제 출력 전이라 끼움 여유(0.25mm)가 프린터에 따라 빡빡하거나 헐거울 수 있음
