# 포트홀 폰 테스트 (웹뷰 앱)

캡스톤 포트홀 감지 프로젝트용 아주 간단한 테스트 앱.
- 폰 가속도 센서로 충격 감지 (C SDK와 같은 계산: |크기-1g|, 0.05초 평균, 쿨다운 2초)
- GPS 위치 기록, 감지 시 위치 붙이기, 지도 링크
- 블랙박스(GPS 없음) 감지 시각을 폰 GPS 기록과 시간으로 맞추기 테스트
- CSV 저장

## 받는 법
- **웹으로 바로**: GitHub Pages 주소 (Settings → Pages 에 표시)
- **안드로이드 앱(APK)**: Actions 탭 → 최신 build → Artifacts 의 `pothole-test-apk` 다운로드 → 압축 풀고 폰에 설치 (출처를 알 수 없는 앱 허용 필요)

## 구조
- `www/index.html` 화면과 감지 로직 전부 (웹뷰가 이걸 띄움)
- `android/` Capacitor 가 만든 안드로이드 프로젝트 (권한: 위치, 진동 / 화면 꺼짐 방지)
- 고칠 땐 `www/index.html` 만 고치고 main 에 올리면 Actions 가 APK·웹페이지 다시 만듦
